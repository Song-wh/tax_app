# 내 세금 한눈에 (tax-app)

국세(홈택스)와 지방세(위택스)에 흩어진 **돌려받을 돈 / 내야 할 돈 / 체납된 돈**을 한 화면에 모아 보고,
AI(Claude)가 **놓친 환급, 경정청구 대상, 납부 우선순위, 다가오는 기한**을 분석해 주는 **본인용** 웹앱입니다.

> 이 앱은 조회와 분석을 돕는 도구입니다. 실제 환급 신청과 납부는 앱이 연결해 주는 홈택스/위택스 화면에서
> **본인이 직접 확인하고 진행**합니다. 복잡한 사안은 세무사 상담을 권장합니다.

## 1. 주요 기능

|---|---|---|
| 대시보드 요약 | 돌려받을 돈 / 내야 할 돈 / 체납 합계와 건수 | ✅ |
| 국세 목록 | 종합소득세, 부가가치세, 원천세, 중간예납, 미수령 환급금 등 (개인·사업자 구분) | ✅ |

## 2. 빠른 시작

### 준비물
- **Node.js 20 이상** (현재 개발 환경: Node 24)
- 인터넷 브라우저

### 실행

```powershell
cd C:\study\tax-app
npm install        # 처음 한 번만
npm run dev
```

브라우저에서 **http://localhost:3000** 을 엽니다.

- 키가 하나도 없어도 **샘플 데이터로 화면은 바로** 볼 수 있습니다.
- "AI 분석 시작" 버튼은 **Claude API 키**를 넣어야 동작합니다 (→ [3-1](#3-1-claude-api-키-ai-분석용)).
- `.env.local` 을 수정한 뒤에는 **서버를 껐다 켜야**(`Ctrl + C` 후 `npm run dev`) 반영됩니다.

## 3. 키 발급 방법

필요한 키는 두 종류입니다.

| 키 | 용도 | 필요 시점 |
|---|---|---|
| Claude API 키 1개 | AI 분석 | **지금** (먼저 받기) |
| CODEF 키 3개 | 홈택스/위택스 실데이터 조회 | 실데이터 연동할 때 |

### 3-1. Claude API 키 (AI 분석용)

1. https://console.anthropic.com 접속 → 회원가입 / 로그인
2. 왼쪽 메뉴 **Billing** (또는 Plans & Billing)
   - 결제수단(해외결제 가능 카드) 등록
   - 크레딧 충전 (**$5 정도면 테스트에 충분**)
3. 왼쪽 메뉴 **API Keys** → **Create Key**
   - 이름 예: `tax-app`
4. 화면에 표시되는 `sk-ant-` 로 시작하는 값을 **바로 복사**
   - ⚠️ 이 값은 **생성할 때 한 번만** 보여줍니다. 잃어버리면 새로 만들어야 합니다.
5. `C:\study\tax-app\.env.local` 파일을 열고 아래처럼 붙여넣기

   ```env
   ANTHROPIC_API_KEY=sk-ant-api03-xxxxxxxxxxxxxxxx
   ```

6. 서버 재시작 → 화면의 **"분석 시작"** 버튼 클릭

### 3-2. CODEF 키 (홈택스/위택스 실데이터 조회용)

CODEF는 홈택스·위택스 같은 공공/금융 사이트 데이터를 API로 조회할 수 있게 해 주는 중계 서비스입니다.
(삼쩜삼, 토스 등도 이런 방식의 중계 API를 사용합니다.)

1. https://codef.io 접속 → 회원가입 / 로그인
2. **마이페이지 → 키 관리**(또는 API 키 관리) 메뉴에서 아래 3개 값 확인

   | 화면 표기 | `.env.local` 항목 | 형태 |
   |---|---|---|
   | Client ID | `CODEF_CLIENT_ID` | 영문+숫자 문자열 |
   | Client Secret | `CODEF_CLIENT_SECRET` | 영문+숫자 문자열 |
   | Public Key (RSA 공개키) | `CODEF_PUBLIC_KEY` | 아주 긴 문자열 (`MIIBIjAN...`) |

3. `.env.local` 에 붙여넣기

   ```env
   CODEF_CLIENT_ID=여기에_클라이언트_아이디
   CODEF_CLIENT_SECRET=여기에_클라이언트_시크릿
   CODEF_PUBLIC_KEY=MIIBIjANBgkqh...(한 줄 그대로)
   CODEF_ENV=sandbox
   ```

#### CODEF 환경 종류 (`CODEF_ENV`)

| 값 | 설명 | 내 실제 데이터 |
|---|---|---|
| `sandbox` | 가입하면 바로 사용. **정해진 가짜 응답**만 돌려줌 | ❌ |
| `demo` | **데모 버전 신청 → 승인** 후 사용. 실제 데이터, 호출 횟수 제한 있음 | ✅ |
| `production` | 정식 계약 (유료, 보통 사업자 필요) | ✅ |

> **본인용이면 `demo` 로 충분합니다.** CODEF 홈페이지에서 데모 버전을 신청하세요.
> 데모/정식 키는 샌드박스 키와 값이 다를 수 있으니, 승인 후 키 관리 화면에서 다시 확인하세요.

## 4. 환경변수(.env.local) 설명

파일 위치: `C:\study\tax-app\.env.local` (양식은 `.env.example` 에도 있습니다)

| 변수 | 필수 | 기본값 | 설명 |
|---|---|---|---|
| `DATA_SOURCE` | | `mock` | `mock` = 샘플 데이터, `codef` = CODEF 실데이터 |
| `ANTHROPIC_API_KEY` | AI 분석 시 | (없음) | Claude API 키 (`sk-ant-...`) |
| `CODEF_CLIENT_ID` | codef 사용 시 | (없음) | CODEF 클라이언트 ID |
| `CODEF_CLIENT_SECRET` | codef 사용 시 | (없음) | CODEF 클라이언트 시크릿 |
| `CODEF_PUBLIC_KEY` | codef 사용 시 | (없음) | CODEF RSA 공개키 (비밀번호 암호화용) |
| `CODEF_ENV` | | `sandbox` | `sandbox` / `demo` / `production` |

작성 규칙:
- `=` 앞뒤에 **공백 없이**, 따옴표 없이 씁니다.
- `#` 으로 시작하는 줄은 주석입니다.
- 이 파일은 `.gitignore` 에 포함되어 있어 git에 올라가지 않습니다.

## 5. 데이터 소스 전환 (샘플 ↔ 실데이터)

```env
DATA_SOURCE=mock    # 샘플 데이터 (src/lib/mock-data.ts)
DATA_SOURCE=codef   # CODEF 실데이터
```

- 화면 오른쪽 위 배지에 현재 소스("샘플 데이터" / "CODEF 실데이터")와 조회 시각이 표시됩니다.
- **현재 `codef` 로 바꾸면**: 키가 올바른지(토큰 발급)까지만 확인하고,
  "조회 연동은 아직 구현 전" 안내가 나옵니다. 실조회 연동 전까지는 `mock` 으로 두세요.

### 샘플 데이터 내용

`src/lib/mock-data.ts` 의 가상 인물 **홍길동**(프리랜서 개발자 + 카페 운영 개인사업자)입니다.
AI가 찾아내는지 확인할 수 있도록 일부러 **놓친 공제**를 심어 두었습니다.

| 심어둔 상황 | AI가 찾아야 하는 것 |
|---|---|
| 72세 무소득 부친과 동거, 신고 시 부양가족 공제 미반영 | 기본공제 + 경로우대 추가공제 경정청구 |
| 2024년 노란우산공제 300만원 납입, 신고에 미반영 | 소기업·소상공인 공제부금 소득공제 경정청구 |
| 부친 의료비 연 약 240만원 | 의료비 세액공제 (요건 확인 필요) |
| 카페 인테리어 1,800만원 세금계산서 | 부가세 매입세액공제 반영 여부 확인 |
| 자동차세·재산세 체납 | 납부 최우선 (가산세 증가) |
| 미수령 국세/지방세 환급금 | 환급계좌 등록 후 수령 |

샘플 내용을 바꾸고 싶으면 이 파일을 직접 수정하면 됩니다 (형식은 [9장](#9-데이터-형식-typests) 참고).

### 상태 값

| 상태 | 의미 | 버튼 |
|---|---|---|
| 환급 가능 (초록) | 돌려받을 돈이 있음 | 환급 신청 |

| 체납 (빨강) | 기한이 지났는데 안 냄 → 가산세 | 납부하기 |
| 납부 예정 (파랑) | 고지/예정된 세금 | 납부하기 |
| 완납 (회색) | 처리 완료 | 없음 |

## 7. AI 분석은 어떻게 동작하나

1. "분석 시작" 클릭 → 브라우저가 `POST /api/analyze` 호출
2. 서버가 현재 데이터 소스에서 세금 데이터를 가져옴
3. 오늘 날짜 + 세금 데이터(JSON)를 Claude에 전달
4. Claude가 **정해진 JSON 형식**(구조화된 출력)으로 답변 → 화면에 표시

### 사용 모델 / 설정 (`src/lib/analyze.ts`)

| 항목 | 값 | 설명 |
|---|---|---|
| 모델 | `claude-opus-5-5` | Claude Opus 5.5 |
| thinking | `adaptive` | 필요한 만큼 스스로 깊게 생각 |
| effort | `high` | 세금 판단은 정확도가 중요해서 높게 설정 |
| 출력 형식 | Zod 스키마 (`AnalysisSchema`) | 항상 같은 구조의 JSON으로 받음 |
| fallback | `fallbacks: "default"` | 모델이 요청을 거절하면 다른 모델이 자동으로 이어받음 |

### 분석 결과 항목

| 항목 | 내용 |
|---|---|
| `summary` | 전체 상황 3~4문장 요약 |
| `refundOpportunities` | 돌려받을 수 있는 돈: 제목, 세목, 귀속연도, 예상액, 근거, 처리 방법, 기한, 가능성(높음/확인 필요/낮음) |
| `paymentPriorities` | 납부 우선순위: 금액, 기한, 이유(가산세 위험 등) |
| `upcomingDeadlines` | 다가오는 신고·납부 기한 |
| `warnings` | 추가 확인이 필요한 점, 세무사 상담 권장 사항 |

### AI 지시 원칙 (시스템 프롬프트 요약)
- 주어진 데이터와 오늘 날짜만 근거로 판단, 금액은 **보수적으로 추정**
- 공제 요건(나이, 소득 100만원 이하 등)이 데이터로 확인 안 되면 가능성을 낮추고 확인할 점에 기록
- 경정청구는 **법정신고기한부터 5년 이내** 기준
- 처리 방법은 홈택스/위택스 메뉴 기준으로 안내, **최종 제출·납부는 사용자가 직접**

> ⚠️ AI 분석은 참고용입니다. 예상 환급액은 추정치이며, 실제 경정청구 전에 홈택스에서 내용을 확인하세요.

## 8. 프로젝트 구조

```
tax-app/
├─ .env.local               # 내 키 (직접 작성, git 제외)
├─ .env.example             # .env.local 양식
├─ src/
│  ├─ app/
│  │  ├─ layout.tsx         # 공통 레이아웃 (제목, 폰트)
│  │  ├─ page.tsx           # 대시보드 (서버 컴포넌트)
│  │  ├─ analysis-panel.tsx # AI 분석 패널 (클라이언트 컴포넌트)
│  │  ├─ globals.css        # 전역 스타일 (Tailwind)
│  │  └─ api/analyze/
│  │     └─ route.ts        # POST /api/analyze — AI 분석 API
│  └─ lib/
│     ├─ types.ts           # 세금 데이터 공통 타입
│     ├─ mock-data.ts       # 샘플 데이터
│     ├─ format.ts          # 금액 표시, 상태 라벨/색상, 바로가기 링크, D-day 계산
│     ├─ analyze.ts         # Claude 호출 + 결과 스키마
│     └─ providers/
│        ├─ index.ts        # DATA_SOURCE 에 따라 mock / codef 선택
│        └─ codef.ts        # CODEF 토큰 발급 (+ 조회 연동 예정)
└─ README.md
```

### 기술 스택

| 영역 | 사용 기술 |
|---|---|
| 프레임워크 | Next.js 16 (App Router), React 19 |
| 언어 | TypeScript |
| 스타일 | Tailwind CSS 4 (다크모드 자동 대응) |
| AI | `@anthropic-ai/sdk` (Claude API) |
| 스키마 | `zod` |
| 데이터 연동 | CODEF API (예정) |

### 새 데이터 소스를 붙이려면
1. `src/lib/providers/` 에 새 파일을 만들고 `TaxProfile` 을 반환하는 함수를 작성
2. `src/lib/providers/index.ts` 에서 `DATA_SOURCE` 값에 따라 그 함수를 호출하도록 추가
3. 화면과 AI 분석은 `TaxProfile` 형식만 맞으면 그대로 동작합니다

## 9. 데이터 형식 (types.ts)

모든 데이터 소스는 아래 `TaxProfile` 형식으로 변환해서 사용합니다.

```ts
TaxProfile {
  source: "mock" | "codef"
  fetchedAt: string                 // 조회 시각 (ISO)
  taxpayer: { name, birthYear, occupation }
  family: FamilyMember[]            // 부양가족 판단용
  businesses: Business[]            // 사업자 정보
  items: TaxItem[]                  // 세금 항목 (환급/미납/체납/예정/완납)
  filings: FilingRecord[]           // 과거 신고 이력
  extraFacts: string[]              // 신고 반영 여부를 확인할 지출/납입 내역
}
```

| 타입 | 주요 필드 |
|---|---|
| `TaxItem` | `scope`(personal/business), `category`(national/local), `taxType`, `period`, `amount`(원), `status`, `dueDate`(YYYY-MM-DD), `agency`, `note` |
| `FilingRecord` | `taxType`, `year`(귀속연도), `filedAt`, `totalIncome`, `deductions[]`, `determinedTax`(결정세액), `prepaidTax`(기납부세액) |
| `FamilyMember` | `relation`, `age`, `annualIncome`, `livesTogether`, `disabled` |
| `Business` | `name`, `bizNo`, `vatType`(일반/간이/면세), `industry`, `openedAt` |

## 11. 보안 · 개인정보 주의사항

세금 데이터에는 주민번호, 소득, 가족 정보 같은 **민감정보**가 들어갑니다.

- `.env.local` 파일(키)은 **절대 공유하거나 git·클라우드에 올리지 마세요.**
- 키가 노출되면 즉시 Anthropic Console / CODEF 에서 해당 키를 **삭제하고 재발급**하세요.
- 이 앱은 **내 PC(localhost)에서만** 실행하는 것을 전제로 합니다. 인터넷에 공개 배포하지 마세요.
  (공개 배포하면 누구나 내 세금 정보와 내 API 크레딧을 쓸 수 있습니다.)
- AI 분석 시 세금 데이터가 Anthropic API로 전송됩니다. Anthropic은 API 데이터를 모델 학습에 사용하지 않지만,
  전송 자체가 싫은 정보는 데이터에서 빼고 사용하세요.
- 실데이터 연동 후에는 조회 결과를 저장할 때 암호화를 적용할 예정입니다 (로드맵 참고).

## 13. 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| `ANTHROPIC_API_KEY 가 .env.local 에 설정되지 않았습니다.` | 키를 안 넣었거나, 넣은 뒤 서버를 재시작하지 않음 |
| `Claude API 키가 올바르지 않습니다.` | 키 복사 시 앞뒤 공백/누락 확인, 또는 키가 삭제됨 → 재발급 |
| `Claude API 오류 (400)` + credit 관련 메시지 | 크레딧 부족 → Console Billing에서 충전 |
| `요청이 너무 많습니다.` | 사용량 한도 초과, 잠시 후 재시도 |
| 분석이 오래 걸림 | 정상입니다. 깊게 생각하므로 **1~2분** 걸릴 수 있습니다 |
| `CODEF_CLIENT_ID / CODEF_CLIENT_SECRET 가 ... 설정되지 않았습니다.` | `DATA_SOURCE=codef` 인데 CODEF 키가 없음 → 키 입력 또는 `mock` 으로 변경 |
| `CODEF 토큰 발급 실패 (401)` | Client ID / Secret 오타, 또는 환경(sandbox/demo) 키 불일치 |
| `CODEF 키는 정상입니다. ... 아직 구현 전입니다.` | 키는 정상. 실조회 연동 전이므로 `DATA_SOURCE=mock` 으로 사용 |
| `npm install` 중 `allow-scripts` 경고 | 무시해도 됩니다 (실행에 영향 없음) |
| 3000 포트가 이미 사용 중 | `npm run dev -- -p 3001` 처럼 다른 포트로 실행 |
